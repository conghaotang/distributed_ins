# 实验目录

直接打开各图的 `figureXX_main.m` 运行。每图主脚本、配置、绘图、Excel和MAT保持同级，共用数据位于 `../data`。数据已统一保存为321姿态的标准七列矩阵。

| 图号 | 实验 |
| --- | --- |
| 00 | 经纬度轨迹 |
| 01、12 | 姿态及解缠 |
| 02、13 | 前50秒航向和位置插值 |
| 03 | 角速度和角加速度 |
| 04、06 | 四陀螺、四加计观测 |
| 05、14 | 比力、向心和切向项 |
| 07、08 | 角速度、比力重构误差，图08读取图07结果 |
| 09 | 姿态、速度、位置误差 |
| 15 | 导航误差 |
| 16 | 双系统原点位置与当地姿态 |
| 17、18 | 双系统理想运动及杆臂分项 |
| 19 | 两套不同参数的正交三轴IMU导航 |
| 20 | 单套分布安装正交三轴IMU导航 |

算法采样参数、传感器原始误差和SI转换位于 `Toolbox/configuration/config.m`、`config_2.m`。实验共用设置位于 `common/experiment_config.m`，各图专用设置位于自己的 `figureXX_config.m`。

在工程根目录的MATLAB命令窗口运行。

```matlab
rootDir=pwd;
addpath(genpath(rootDir));
summary=run_all_experiments(120); % 前120秒
% summary=run_all_experiments(Inf); % 完整输入轨迹
```

当前结果文件由前120秒的100Hz实验生成。

输入数据在各图主脚本开头的 sourceFile 中直接指定完整路径。实验配置不再保存数据类别或输入文件名。各主脚本直接使用 load 读取 MAT 文件中的 avp 并截取实验时长，运行时包含工程的全部子目录。所有输入使用相同读取和计算流程；共用导航误差绘图及导出统一使用秒（s）和米（m）。
